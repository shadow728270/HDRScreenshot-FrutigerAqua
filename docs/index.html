GOOD TO KNOW

Frequently asked questions.

Does HDRSnip Fusion work with Windows Auto HDR?

It's designed for HDR and Auto HDR content using DXGI Desktop Duplication and adjustable tone mapping. Actual capture behavior depends on your monitor, driver, and the game's display mode. Borderless fullscreen is generally safer than exclusive fullscreen.

Are screenshots saved in real HDR?

Not currently. HDRSnip Fusion uses an HDR-aware capture path, then converts the image into a conventional tone-mapped SDR PNG for sharing. The exported file does not preserve native HDR metadata.

Is v0.1.2 free? Is the code open source?

Yes. The application is free and the code is available on GitHub under the MIT License.

Do I need Python or an installer?

No. Download and launch HDRSnipFusion.exe on Windows 10 or 11. Python is only necessary if you want to run or build the source yourself.

What about Windows SmartScreen?

This early public EXE is unsigned, so Windows SmartScreen may warn. Use the official GitHub release and SHA-256 checksum to verify the file. Avoid downloading lookalike copies from unofficial sources.

My hotkey doesn't work. What should I check?

Open Settings from the tray icon to check the configured hotkey. Another program might already be using that combination, and a saved hotkey may be different from the default Ctrl + Shift + X.
