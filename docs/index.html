Prismwake v0.2.0 Highlights
  • Pinned Floating Screenshots: Keep multiple captures always-on-top, resize with locked aspect ratio, adjust opacity (15%–100%), or zoom 25%–300%.
  • 100% Offline OCR: Extract code, error dialogs, and UI text locally with word/line bounding boxes — no cloud uploads or Windows store package requirements.
  • Persistent SQLite + FTS5 History: Local gallery with instant full-text search, favorites, privacy modes, and automatic storage retention limits.
  • Smart Capture Modes: Region, DWM Window Capture, Multi-Monitor Fullscreen HDR Capture, Delayed Countdown (3s/5s/10s), and direct Text Capture.

Preserved 64-Bit scRGB HDR Pipeline

          

            Prismwake v0.2.0 preserves every detail of the v0.1.4 DXGI Desktop Duplication pipeline
            (DXGI_FORMAT_R16G16B16A16_FLOAT), per-monitor Windows DISPLAYCONFIG_SDR_WHITE_LEVEL
            querying, and C1-continuous highlight roll-off. OCR and History operate on the tone-mapped display
            representation without altering your original capture buffer.
          

        

        

          
Single-Executable Architecture & Simple Upgrade

          

            Starting in v0.2.0, Prismwake.exe is the sole Windows executable built and published,
            paired with Prismwake.exe.sha256. Existing installations running Prismwake.exe update
            automatically with SHA-256 + PE64 verification and automatic rollback.
