STRAIGHT ANSWERS

Before you jump in.

Does the app capture native HDR image files?

It uses HDR-aware DXGI capture and converts the captured data into tone-mapped SDR PNGs. True HDR file export is a future idea, not a current feature.

Is Prismwake free, and is its source available?

Yes. It is MIT licensed and free. The existing repository contains the current Python application source and historical releases.

Why does the downloadable file have another name?

This is a staged rebrand. The website and documentation now use Prismwake. Keeping the current EXE filename, program data paths, and GitHub updater endpoints intact prevents breaking the v0.1.2 installation. Desktop app branding will be updated separately.

Does the browser demo actually capture my screen?

No. The mini editor is a safe, local interactive prototype. The comparison viewer uses its bundled illustration or screenshots you select directly from your device. Selected images are processed in your browser and aren't uploaded.

Does Prismwake work with fullscreen games?

It captures before opening the editor overlay. Borderless fullscreen tends to be more reliable; exclusive fullscreen can still minimize or behave differently depending on drivers and game settings.
