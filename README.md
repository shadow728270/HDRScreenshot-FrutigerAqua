# HDRScreenshot FrutigerAqua

**HDR Screenshots**

A free, open-source screenshot and annotation tool for Windows, featuring a Frutiger Aqua-inspired interface.

### Features

- **HDR Support:** Capture HDR, Auto HDR, and SDR content using DXGI Desktop Duplication.
- **Frutiger Aqua UI:** Animated water effects, transparent glass, and glossy jelly-style buttons.
- **Screenshot Editing:** Draw, add shapes, arrows, and text to screenshots.
- **Multi-Monitor Support:** Capture screenshots across different displays and resolutions.
- **Customizable Settings:** Adjust HDR tone mapping, animations, transparency, and hotkeys.
- **Quick Capture:** Use a customizable keyboard shortcut to enter screenshot mode.
- **System Tray Integration:** Runs quietly in the background with optional Windows startup.
- **Easy Export:** Save screenshots as images or copy them directly to your clipboard.

### Requirements

- Windows 10 or 11
- No Python installation required when using the Windows executable.
