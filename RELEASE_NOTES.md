# HDRScreenshot FrutigerAqua v0.1.0

First public Windows release of HDRSnip Fusion, a free HDR-aware screenshot and annotation application with a Frutiger Aqua interface.

## Features
- Capture SDR, HDR, and Auto HDR desktops with DXGI Desktop Duplication.
- Frutiger Aqua glass interface, animated caustics, and jelly-style buttons.
- Screenshot selection, annotation, and save or clipboard export.
- Multi-monitor awareness, adjustable hotkeys, HDR tone mapping, and system-tray startup.
- No separate Python installation needed for the Windows executable.

## Installation
1. Download `HDRSnipFusion.exe` below.
2. Run it on Windows 10 or 11 (64-bit).
3. Find the application in the system tray and use the configured capture hotkey (default: Ctrl+Shift+X).

**Note:** This is an unsigned, early public build. Windows SmartScreen may display a warning. Build success does not replace testing on a Windows PC.
